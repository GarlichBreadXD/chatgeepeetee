# ChatGeePeeTee 💨🤖

A delightfully useless vape-addicted chatbot built with HTML, CSS, and vanilla JavaScript. Features keyword-based responses, parental controls, and mental health support.

## Features

✨ **Single File App** - Everything is contained in `index.html`
- No dependencies needed, just open the file!

🎨 **Beautiful Design**
- Modern dark theme with cyan/pink neon aesthetics
- Fully responsive (mobile & desktop)
- Animated vape pen logo
- Chat history sidebar

💬 **ChatGeePeeTee Personality**
- Super useless bot obsessed with blue razz vapes
- Keyword-based intelligent responses
- Contextual replies based on what you ask
- Slightly funny but serious mental health support

⚙️ **Parental Controls**
- **Vape Mode Toggle** - Turn off vape addiction (bot criticizes vaping instead)
- **Disable Cursing** - Removes mild language
- **Custom Name** - Personalize how the bot addresses you

💙 **Mental Health Support**
- Detects keywords: suicide, self-harm, depression, hopelessness, etc.
- Responds with compassion and provides crisis resources:
  - **National Suicide Prevention Lifeline: 988**
  - **Crisis Text Line: Text HELLO to 741741**

## How to Use

1. Simply open `index.html` in your web browser
2. No installation, no dependencies required
3. Your chat history and settings are saved locally in your browser

## Technologies

- HTML5
- CSS3 (with gradients and animations)
- Vanilla JavaScript (ES6+)
- LocalStorage for data persistence
- Font Awesome Icons

## Browser Support

Works on all modern browsers (Chrome, Firefox, Safari, Edge, etc.)

Enjoy your useless conversations! 🌬️✨
